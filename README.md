# Counter Clicker

A simple native Android counter app written in Kotlin. It includes:
- Tap to add 1
- Minus 1 (won't go below zero)
- Reset
- Automatically saves the count on the device

## Build an APK
1. Install Android Studio on a computer.
2. Open this project folder in Android Studio.
3. Let Gradle sync and install any requested Android SDK components.
4. Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. The APK will be available under `app/build/outputs/apk/debug/`.

To install directly from Android Studio, connect an Android phone with USB debugging enabled and press Run.
